## 테스트 기본 설정의 앞선 실행

운영 설정(`jit=off`, `prepareThreshold=0`)으로 맞추기 전에 테스트 기본값(`jit=on`, `prepareThreshold=5`)으로 잰 값이다. 운영 설정이 왜 필요했는지와 두 형태의 결과가 같은지를 보여 주려고 남긴다.

같은 쿼리(최근 열람순 WHERE, 1,000번째)가 실행 순서에 따라 갈렸다.

| 실행 | 중앙값(ms) | 5회(ms, 오름차순) |
| --- | --- | --- |
| 형태 비교 실행 | 35.38 | 35,35,35,38,38 |
| 위 표의 공식 측정을 같은 설정으로 돌린 실행 | 44.12 | 40,42,44,53,68 |

두 형태가 돌려준 행의 id를 순서까지 비교한 결과, 제목순·최근 열람순 모두 50·1,000·5,000·9,000번째 위치에서 10행이 같았다. 운영 설정으로 맞춘 뒤에는 이 비교를 다시 돌리지 않았다.
